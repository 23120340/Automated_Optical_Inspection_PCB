# Docs

Xếp theo **việc bạn đang cần làm**, không theo thời gian viết.

| Nhóm | Đọc khi | Nội dung |
|---|---|---|
| [reports/](reports/) | muốn biết dự án đang ở đâu | báo cáo tiến độ, tổng kết, và **bảng công việc sống** `tien_do_detect_2_luot.md` |
| [plans/](plans/) | trước khi bắt tay làm một hạng mục | kế hoạch từng bước, phương án đã cân nhắc và lý do chọn |
| [surveys/](surveys/) | trước khi đi tìm dữ liệu hoặc model | ngoài kia có gì, cái nào dùng được, cái nào là bẫy |
| [evaluation/](evaluation/) | trước khi tin một model | số đo thật, xếp hạng, rà soát lỗi |
| [design/](design/) | khi cần hợp đồng kỹ thuật | thiết kế Position/Golden, yêu cầu camera, định dạng CAD, file mẫu |
| [bench/](bench/) | khi so hai lần chạy | kết quả benchmark thô |
