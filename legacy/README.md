# Prototype cũ

Thư mục này giữ bản AOI đời đầu (`KCS_Inspec_PCBA_V2.exe`) và `rtsp.txt` để tham
chiếu. Cả hai đều **không commit vào Git**: file exe nặng ~130 MB, còn `rtsp.txt`
chứa thông tin đăng nhập camera.

Không có gì trong `aoi_pipeline/` hay `app/` phụ thuộc vào thư mục này. Nếu clone
repo mới thì thư mục này sẽ trống — đó là điều bình thường.
